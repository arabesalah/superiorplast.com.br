# Superiorplast

Site moderno com backend simples para catálogo de cadeiras da Superiorplast.

## Como rodar

1. Instale as dependências:
   - npm install
2. Inicie o servidor:
   - npm start
3. Acesse no navegador:
   - http://localhost:3000

## Produtos iniciais

- Cadeira Bistro — R$ 44,90
- Cadeira Poltrona — R$ 54,90
- Cadeira Poltrona Robusta XL — R$ 64,90
